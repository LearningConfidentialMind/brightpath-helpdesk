A few words made simple
Browser
The app you use to visit websites, such as Chrome. It draws the page and runs the page's JavaScript.
Server / Worker
A program running in the cloud. It receives requests and sends back pages or answers. This app uses a Cloudflare Worker.
HTML
The page's structure: headings, text boxes, buttons and links.
CSS
The page's appearance: colors, fonts, spacing and phone layouts.
JavaScript
Instructions that make things happen. Here it runs both in the browser and on the server.
API / endpoint
A way for programs to talk. An endpoint is an address for a particular task, such as /api/ask for questions.
JSON
A text format for sharing data, using named fields and lists. It is not a language model.
Function
A named set of instructions that can be reused, like a small recipe.
Variable / const
A name for a stored value. JavaScript's const means that name cannot be reassigned.
await
Wait for an unfinished operation, such as receiving a server reply, before continuing this task.
Mock
A clearly labelled demonstration using fixed rules. It does not call an AI model.
Citation
A reference to the document that supplies the answer's evidence.
HTTP status
A response number: 200 means success, 400 means invalid input, and 503 means a service is unavailable.
Build
A preparation step that joins the readable source files into the one file used by the cloud host.
